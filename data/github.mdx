## Additional Instructions

After you authorize Stoneturner, provide a comma-separated list of repositories to sync (for example, `owner/repo1, owner/repo2`). Stoneturner syncs issues, pull requests, docs, discussions, and source code from those repositories into searchable markdown.

## Running Stoneturner Locally

| | |
|:-|:-|
| Authentication | OAuth based |
| External App | Create an app at [GitHub Developer Settings](https://github.com/settings/developers) |
| Docs | [GitHub docs](https://docs.github.com) |
