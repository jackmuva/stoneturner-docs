## Running Stoneturner Locally

| | |
|:-|:-|
| Authentication | OAuth based |
| External App | Create an app at [HubSpot Developer Portal](https://developers.hubspot.com/) |
| Docs | [HubSpot API docs](https://developers.hubspot.com/docs/api/overview) |

Stoneturner syncs contacts, companies, and deals into queryable SQLite tables. CRM records are structured, so agents can search them with SQL rather than vector search.
